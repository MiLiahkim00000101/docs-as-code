# API

API предоставляет доступ к функциям ИИ-сервиса.

## Основные операции

- `POST /reviews` — Классифицировать тональность отзыва;
- `POST /analysis` — Запросить среднюю тональность отзывов о товаре;
- `GET /analysis/{id}` — Получить результат аналитики по идентификатору;

## Спецификация

Полное описание API находится в файле `openapi.yaml`

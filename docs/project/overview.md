# Анализатор отзывов

Сервис автоматически определяет тон отзыва и присваивает ему категорю от положительного до негативного.

Основные пользователи:
- платформы, на которых есть возможность оставлять отзывы в том или ином виде (платформы);
- человек, оценивающий качество какого-либо продукта, услуги или проекта на платформе (пользователь).

Основные функции:
- отправка отзыва;
- определение тона отзыва;
- просмотр результата анализа.

## Комплект документации

1. Описание проекта
Здесь написано о том, что делает проект, как им можно пользоваться и для чего он предназначен. 
Для пользователей, разработчиков и владельцев бизнеса, которые планируют внедрить это ПО.
2. Требования
В этом разделе описаны требования к девайсам, на которых можно пользоваться данным ПО, версиям программных обеспечений и фреймворкам, а так же непосредственно то, что данная система позволяет делать и каким функционалом обладает. 
Для всех - и разработчиков и пользователей и бизнесов, желающих внедрить это ПО.
3. Архитектура системы
Служит для понимания того, как работает система, какое количество устройств и передач данных требуется для работы системы.
Для разработчиков.
4. Документация API
Содержит набор функций API и их описание.
Для разработчиков.
5. Документация ML-модели
Содержит результаты бенчмарков используемых в ПО ML-моделей, то, в каких задачах и при каких условиях они проявляют лучший результат, на каких данных обучена и на каких протестирована.
Для разработчиков.
6. Руководство пользователя
Необходимо для знакомства с тем, как пользоваться ПО, в каких областях документации искать инструменты для выполнения задач, примеры использования ПО.
Для разработчиков.
